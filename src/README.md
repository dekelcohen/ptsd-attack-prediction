# Booggii PTSD Research

### Download participants data
The data by the Empatica Health Monitoring Platform is securely stored and encrypted within Amazon S3 bucket.
1. Follow Cyberduck instructions:
https://support.empatica.com/hc/en-us/sections/13882366923421-Accessing-your-Data  
You need the project's:  
ACCESS KEY ID, SECRET ACCESS KEY & S3 ACCESS URL
2. Download relevant participant data. Keep empatica's dir structure.
